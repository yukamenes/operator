> **Як працювати з цією шпаргалкою**
> 1. Читай по одному розділу. Не поспішай.

## 1. Навіщо програмі вміти вирішувати

У житті ти постійно вирішуєш:

- **Якщо** на вулиці дощ — беру парасольку. **Інакше** — не беру.
- **Якщо** є гроші — купую морозиво.
- **Якщо** будильник задзвонив — встаю.

Програма теж має вміти так робити: **перевірити щось** і **вибрати, що робити далі**.

Для цього потрібні дві речі:

| Що | Навіщо |
|---|---|
| **Питання**, на яке можна відповісти «так» або «ні» | Це робить `bool` і оператори порівняння |
| **Вибір дії** залежно від відповіді | Це робить `if`, `elif`, `else` |

Спочатку розберемо питання, потім — вибір.

## 2. Тип `bool`: «Так» і «Ні» в Python

### Що це?

`bool` — це тип даних, який має **лише два значення**:

| Значення в Python | Що воно означає |
|---|---|
| `True` | Так, правда |
| `False` | Ні, неправда |

Уяви вимикач світла: він або **увімкнений**, або **вимкнений**. Третього варіанту немає. `bool` працює так само.

### Приклад

```python
rain = True          # дощ іде
sunny = False        # сонця немає

print(rain)          # True
print(sunny)         # False
print(type(rain))    # <class 'bool'>
```

### ⚠️ Запам'ятай

- Пишемо **саме** `True` і `False` — **з великої літери**.
- `true`, `TRUE`, `false` — Python не розуміє, буде помилка.
- `True` без лапок — це `bool`. А `"True"` в лапках — це просто **текст**, не `bool`.

```python
a = True       # bool  ✅
b = "True"     # рядок (просто слово) ❌ це не bool
```

### А звідки береться `True` і `False`?

Найчастіше їх **не пишуть вручну**. Вони виникають, коли ми **щось порівнюємо**. Про це — наступний розділ.

## 3. Оператори порівняння

### Ідея

Порівняння — це **питання**. Python відповідає на нього `True` («так») або `False` («ні»).

```python
print(5 > 3)     # Чи 5 більше за 3?   → True
print(5 < 3)     # Чи 5 менше за 3?    → False
```

### Усі оператори порівняння

| Запис | Як читати | Питання | Приклад | Результат |
|:---:|---|---|---|:---:|
| `==` | дорівнює | Вони однакові? | `5 == 5` | `True` |
| `!=` | не дорівнює | Вони різні? | `5 != 3` | `True` |
| `>` | більше | Ліве більше за праве? | `5 > 3` | `True` |
| `<` | менше | Ліве менше за праве? | `5 < 3` | `False` |
| `>=` | більше або дорівнює | Ліве не менше за праве? | `5 >= 5` | `True` |
| `<=` | менше або дорівнює | Ліве не більше за праве? | `4 <= 2` | `False` |

💡 **Лайфхак:** завжди читай порівняння вголос як питання.
`age >= 18` → «Чи вік **не менший за** 18?»

### 🔴 Найважливіше: `=` і `==` — це РІЗНІ речі!

| Запис | Що робить | Приклад |
|:---:|---|---|
| `=` | **Кладе** значення в змінну («запиши») | `age = 15` |
| `==` | **Питає**, чи рівні значення («чи однакові?») | `age == 15` |

```python
age = 15          # Записали: у змінній age тепер 15
print(age == 15)  # Питаємо: age дорівнює 15? → True
print(age == 20)  # Питаємо: age дорівнює 20? → False
```

Одне `=` — **наказ** («зроби так»). Два `==` — **питання** («а чи так?»).

### Порівняння слів (рядків)

Порівнювати можна не лише числа, а й слова:

```python
name = "Олена"
print(name == "Олена")   # True
print(name == "Іван")    # False
print(name != "Іван")    # True
```

⚠️ Великі та малі літери — це **різні** символи:

```python
print("кіт" == "Кіт")    # False !
```

### ⚠️ Число і текст — не одне й те саме

```python
print(5 == "5")    # False — число 5 і текст "5" не рівні
```

Тому, коли користувач вводить число, його треба перетворити через `int()` (див. розділ 4).

### 📝 Практика 1. Передбач результат

Спочатку **подумай**, що виведе Python, запиши відповідь у зошит. Потім запусти й перевір.

```python
print(5 > 3)
print(5 == 3)
print(10 != 10)
print(7 <= 7)
print(2 >= 9)
print("кіт" == "кіт")
print("кіт" == "Кіт")
print(4 + 1 == 5)
print(3 < 2)
print("a" != "b")
```

## 4. Мінідовідка: `input()` та `int()`

Щоб програма могла питати користувача, потрібні дві команди.

### `input()` — спитати користувача

```python
name = input("Як тебе звати? ")
print("Привіт,", name)
```

> ⚠️ `input()` **завжди** повертає **текст** (рядок), навіть якщо ти ввів цифри.

### `int()` — перетворити текст на ціле число

```python
age = int(input("Скільки тобі років? "))
```

Так це читається зсередини назовні:
1. `input(...)` — спитали й отримали текст, наприклад `"15"`.
2. `int(...)` — перетворили текст `"15"` на число `15`.
3. `age = ...` — поклали число в змінну `age`.

| Коли що використовувати |  |
|---|---|
| Потрібне **слово** (ім'я, пароль, колір) | `input(...)` |
| Потрібне **число** (вік, оцінка, температура) | `int(input(...))` |

## 5. Умовний оператор `if`

### Що це?

`if` у перекладі — **«якщо»**.

> **Якщо** умова правдива (`True`) — виконай певні дії.
> **Якщо** ні (`False`) — просто пропусти їх.

### Синтаксис (як записувати)

```python
if умова:
    дія
```

Три важливі речі:

1. Після умови стоїть **двокрапка** `:`
2. Дії пишуться **з відступом** (4 пробіли або одне натискання `Tab`)
3. Відступ показує Python: «ці рядки належать до `if`»

### Блок-схема

> Як читати: прямокутник із закругленнями — початок; подвійна рамка — **питання**; звичайна рамка — **дія**.

```
        ┌───────────┐
        │   Старт   │
        └─────┬─────┘
              │
              ▼
       ╔═════════════╗
       ║   Умова ?   ║─────── False (Ні) ───────┐
       ╚══════╤══════╝                          │
              │ True (Так)                      │
              ▼                                 │
     ┌─────────────────┐                        │
     │ Дії всередині if│                        │
     └────────┬────────┘                        │
              │                                 │
              ▼                                 │
     ┌─────────────────────────────────┐◄───────┘
     │      Решта програми             │
     └─────────────────────────────────┘
```

### Приклад 1

```python
weather = "дощ"

if weather == "дощ":
    print("Бери парасольку!")

print("Гарного дня!")
```

**Що відбувається, крок за кроком:**

1. Python перевіряє: `weather == "дощ"` → це `True`.
2. Тому виконується рядок з відступом: `Бери парасольку!`
3. Рядок `Гарного дня!` **без відступу** — він не належить до `if`, тому виконається **завжди**.

**Результат:**
```
Бери парасольку!
Гарного дня!
```

А тепер змінимо одне слово: `weather = "сонце"`.

1. Умова `weather == "дощ"` → `False`.
2. Python **пропускає** рядок з відступом.
3. Виконується лише `Гарного дня!`.

**Результат:**
```
Гарного дня!
```

### Приклад 2: з числом

```python
money = int(input("Скільки в тебе грошей? "))

if money >= 50:
    print("Можна купити морозиво!")

print("Кінець програми")
```

| Ввели | Умова `money >= 50` | Що надрукує програма |
|:---:|:---:|---|
| `100` | `True` | Можна купити морозиво! / Кінець програми |
| `50` | `True` | Можна купити морозиво! / Кінець програми |
| `20` | `False` | Кінець програми |

### 🔑 Відступ — це дуже важливо!

```python
if 5 > 3:
    print("Це всередині if")     # виконається тільки якщо умова True
print("Це поза if")              # виконається завжди
```

Якщо після `if` кілька рядків з однаковим відступом — усі вони всередині:

```python
if 5 > 3:
    print("Перший рядок")
    print("Другий рядок")
    print("Третій рядок")
```

## 6. `if` + `else`

### Що це?

`else` у перекладі — **«інакше»**.

> **Якщо** умова правдива — зроби **одне**.
> **Інакше** — зроби **інше**.

Тепер програма **завжди** робить **щось одне з двох**.

### Синтаксис

```python
if умова:
    дії, якщо True
else:
    дії, якщо False
```

- `else` пишеться **на тому ж рівні**, що й `if` (без відступу відносно нього).
- Після `else` теж **двокрапка**.
- У `else` **немає умови** — він ловить усе, що не підійшло.

### Блок-схема

```
          ┌──────────┐
          │  Старт   │
          └────┬─────┘
               │
               ▼
        ╔═════════════╗
        ║   Умова ?   ║
        ╚══╤═══════╤══╝
           │       │
     True  │       │  False
    (Так)  │       │  (Ні)
           ▼       ▼
     ┌─────────┐ ┌──────────┐
     │ Блок if │ │Блок else │
     └────┬────┘ └────┬─────┘
          │           │
          └─────┬─────┘
                │
                ▼
        ┌───────────────┐
        │Решта програми │
        └───────────────┘
```

Зверни увагу: шляхи **розходяться**, а потім **сходяться** знову. Виконується **лише одна** гілка.

### Приклад 1

```python
age = int(input("Скільки тобі років? "))

if age >= 18:
    print("Ти повнолітній")
else:
    print("Ти неповнолітній")
```

| Ввели | `age >= 18` | Результат |
|:---:|:---:|---|
| `20` | `True` | Ти повнолітній |
| `18` | `True` | Ти повнолітній |
| `15` | `False` | Ти неповнолітній |

### Приклад 2: пароль

```python
password = input("Введи пароль: ")

if password == "python123":
    print("Ласкаво просимо!")
else:
    print("Невірний пароль!")
```

### 💡 Як це запам'ятати

`if / else` — це **розвилка на дорозі**. Іти можна **тільки в один бік**. Ніколи — в обидва одразу.

## 7. `if` + `elif` + `else`

### Навіщо потрібен `elif`?

Іноді варіантів **більше, ніж два**. Наприклад, число може бути:
- додатним,
- від'ємним,
- або нулем.

Це **три** варіанти. `if/else` дає лише два. Тут допомагає `elif`.

`elif` — це скорочення від **else if**, тобто **«а якщо ні, то перевір ще таке»**.

### Синтаксис

```python
if умова1:
    дії 1
elif умова2:
    дії 2
elif умова3:
    дії 3
else:
    дії, якщо жодна умова не підійшла
```

### Правила

- `if` — **завжди перший**, і він **один**.
- `elif` — **скільки завгодно** (0, 1, 2, 10 …), у кожного **своя умова**.
- `else` — **максимум один**, **в кінці**, **без умови**. Його можна й не писати.
- Виконається **лише один** блок — той, чия умова **першою** виявилась `True`. Решта **пропускаються**.

### Блок-схема

```
       ┌───────────┐
       │   Старт   │
       └─────┬─────┘
             │
             ▼
      ╔═════════════╗
      ║  Умова 1 ?  ║── True ──► [ Блок 1 ] ───────┐
      ╚══════╤══════╝                              │
             │ False                               │
             ▼                                     │
      ╔═════════════╗                              │
      ║  Умова 2 ?  ║── True ──► [ Блок 2 ] ───────┤
      ╚══════╤══════╝                              │
             │ False                               │
             ▼                                     │
      ╔═════════════╗                              │
      ║  Умова 3 ?  ║── True ──► [ Блок 3 ] ───────┤
      ╚══════╤══════╝                              │
             │ False                               │
             ▼                                     │
       [ Блок else ] ──────────────────────────────┤
                                                   │
                                                   ▼
                                           ┌───────────────┐
                                           │Решта програми │
                                           └───────────────┘
```

💡 Уяви **сходи вниз**: Python перевіряє питання **зверху вниз**. Як тільки отримав «Так» — виконує дії й **більше не перевіряє** нічого.

### Приклад 1: додатне, від'ємне чи нуль

```python
number = int(input("Введи число: "))

if number > 0:
    print("Число додатне")
elif number < 0:
    print("Число від'ємне")
else:
    print("Це нуль")
```

| Ввели | `number > 0` | `number < 0` | Що надрукує програма |
|:---:|:---:|:---:|---|
| `5` | `True` | *(не перевіряється)* | Число додатне |
| `-3` | `False` | `True` | Число від'ємне |
| `0` | `False` | `False` | Це нуль |

### Приклад 2: рівні оцінок (12-бальна шкала)

```python
grade = int(input("Введи оцінку (1-12): "))

if grade >= 10:
    print("Високий рівень")
elif grade >= 7:
    print("Достатній рівень")
elif grade >= 4:
    print("Середній рівень")
else:
    print("Початковий рівень")
```

Давай простежимо, що буде, якщо ввести `8`:

1. `8 >= 10`? **Ні** → йдемо далі.
2. `8 >= 7`? **Так!** → друкуємо «Достатній рівень».
3. Решту умов Python **вже не дивиться**.

### Приклад 3: світлофор

```python
color = input("Який колір світлофора? ")

if color == "червоний":
    print("Стій!")
elif color == "жовтий":
    print("Приготуйся")
elif color == "зелений":
    print("Йди!")
else:
    print("Такого кольору на світлофорі немає")
```

### 🔴 Порядок умов має значення!

Дивись, що буде, якщо поставити умови **не в тому порядку**:

```python
grade = 11

if grade >= 4:
    print("Середній рівень")        # ← спрацює ЦЕ, і все!
elif grade >= 7:
    print("Достатній рівень")
elif grade >= 10:
    print("Високий рівень")
```

Оцінка `11`, а програма скаже «Середній рівень». Чому? Бо `11 >= 4` — це `True`, Python **зупиняється на першій правдивій умові** і далі не йде.

**Правило:** якщо умови схожі (`>= 10`, `>= 7`, `>= 4`), починай з **найстрогішої** (найбільшого числа).

### 🔵 `elif` чи кілька окремих `if`?

Це **різні речі**!

**З `elif`** — виконається **один** блок:

```python
temp = 35

if temp > 30:
    print("Спекотно")
elif temp > 20:
    print("Тепло")
elif temp > 10:
    print("Прохолодно")
```
Результат: `Спекотно`

**З окремими `if`** — кожен `if` перевіряється **сам по собі**:

```python
temp = 35

if temp > 30:
    print("Спекотно")
if temp > 20:
    print("Тепло")
if temp > 10:
    print("Прохолодно")
```
Результат:
```
Спекотно
Тепло
Прохолодно
```

Усі три умови правдиві, тому всі три виконались. Це майже ніколи не те, чого ми хочемо.

> **Правило:** потрібен вибір **одного** варіанта з кількох → `if` + `elif` + `else`.

## 8. Типові помилки

| ❌ Помилка | Приклад | ✅ Як правильно |
|---|---|---|
| Забули двокрапку | `if age >= 18` | `if age >= 18:` |
| Одне `=` замість `==` | `if age = 18:` | `if age == 18:` |
| Немає відступу | `if x > 5:`<br>`print("Так")` | `if x > 5:`<br>`····print("Так")` |
| Різні відступи в одному блоці | 4 пробіли в одному рядку, 2 в іншому | Усі рядки блоку — **однакові** відступи |
| Умова в `else` | `else age < 18:` | `else:` — без умови! |
| `elif` без `if` | починаємо з `elif` | Завжди починай з `if` |
| `true` / `false` з малої літери | `x = true` | `x = True` |
| Число ввели, але не перетворили | `age = input()`<br>`if age > 18:` | `age = int(input())` |
| Порівняли число з текстом | `5 == "5"` → `False` | Перетвори: `int("5") == 5` |
| Неправильний порядок `elif` | `>= 4` перед `>= 10` | Спочатку найстрогіша умова |

### 🛠 Якщо програма видає помилку — що робити?

1. **Прочитай** останній рядок помилки. Він каже, **що** не так.
2. Подивись, на якому **рядку** проблема (Python вказує номер).
3. Перевір по порядку: **двокрапка? відступ? `==` чи `=`? лапки?**
4. Не вийшло — покажи вчителю. Це нормально!

| Повідомлення | Що воно означає простими словами |
|---|---|
| `SyntaxError: expected ':'` | Забув двокрапку |
| `IndentationError: expected an indented block` | Забув відступ після `if` / `else` / `elif` |
| `SyntaxError: invalid syntax` | Щось записано неправильно (часто `=` замість `==`) |
| `NameError: name 'x' is not defined` | Змінної `x` ще немає (помилка в імені або забув створити) |
| `ValueError: invalid literal for int()` | Хотів перетворити на число те, що числом не є (наприклад, літери) |

## 10. Міні-підсумок

### Головне — в одній табличці

| Що | Що робить | Приклад |
|---|---|---|
| `bool` | Тип даних: лише `True` або `False` | `is_rain = True` |
| `==` | Чи **рівні**? | `age == 15` |
| `!=` | Чи **різні**? | `name != "Іван"` |
| `>` `<` | Більше? Менше? | `money > 50` |
| `>=` `<=` | Більше або рівне? Менше або рівне? | `age >= 18` |
| `if` | **Якщо** умова `True` — виконай | `if x > 0:` |
| `else` | **Інакше** (без умови) | `else:` |
| `elif` | **А якщо ні, то ще перевір** | `elif x < 0:` |

### Шаблон, який можна підглядати

```python
# Два варіанти
if умова:
    # що робити, якщо True
else:
    # що робити, якщо False


# Кілька варіантів
if умова1:
    # варіант 1
elif умова2:
    # варіант 2
elif умова3:
    # варіант 3
else:
    # усі інші випадки
```

### Чеклист перед запуском

- [ ] Після `if`, `elif`, `else` стоїть **двокрапка** `:`
- [ ] Дії всередині мають **відступ** (4 пробіли)
- [ ] У порівнянні — `==`, а не `=`
- [ ] Число з `input()` перетворене через `int()`
- [ ] Слова написані **в лапках**, змінні — **без лапок**
- [ ] В `elif` умови йдуть у правильному порядку
- [ ] `else` — без умови
